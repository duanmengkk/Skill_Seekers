# 代码打包指南

## 项目信息

- **包名**: `skill-seekers`
- **版本**: 3.4.0
- **构建系统**: setuptools + wheel
- **Python 版本**: >=3.10
- **包路径**: `src/skill_seekers/` (src layout)

## 安装方式

```bash
# 基本安装
pip install skill-seekers

# 开发模式安装
pip install -e .

# 带所有依赖
pip install -e ".[all]"

# 带开发依赖
pip install -e ".[dev]"
```

## 可选依赖组

| 组名 | 说明 |
|------|------|
| `mcp` | MCP 服务器支持 |
| `gemini` / `openai` / `kimi` / `deepseek` / `qwen` | LLM 平台 |
| `all-llms` | 所有 LLM 平台 |
| `chroma` / `weaviate` / `pinecone` / `rag-upload` | 向量数据库 |
| `s3` / `gcs` / `azure` / `all-cloud` | 云存储 |
| `docx` / `epub` / `pptx` | 文档格式 |
| `video` / `video-full` | 视频处理 |
| `browser` | 浏览器渲染 (Playwright) |
| `embedding` | Embedding 服务器 |
| `all` | 所有可选依赖 |

## 打包发布

```bash
# 1. 安装构建工具
pip install build

# 2. 构建 sdist 和 wheel
python -m build

# 3. 发布到 PyPI
pip install twine
twine upload dist/*

# 或使用 uv (更快)
pip install uv
uv publish dist/*
```

## 项目结构

```
pyproject.toml          # 项目配置 (build backend, 依赖, 入口点)
src/skill_seekers/      # 主包
├── cli/                # CLI 命令
├── adaptors/           # 平台适配器
├── mcp/                # MCP 服务器
└── _version.py         # 版本读取
```

## 入口点 (scripts)

```toml
[project.scripts]
skill-seekers = "skill_seekers.cli:main"
skill-seekers-create = "skill_seekers.cli.create_command:main"
skill-seekers-package = "skill_seekers.cli.package_skill:main"
# ... 共 30+ 个子命令
```

## 发布流程 (GitHub Actions)

参考 `.github/workflows/release.yml`:

1. 触发: 打 tag (如 `v3.4.0`)
2. 运行测试
3. 验证版本号匹配
4. 构建并发布到 PyPI

## 本地测试打包

```bash
# 构建
python -m build

# 查看生成的文件
ls dist/

# 本地安装测试
pip install dist/skill_seekers-3.4.0-py3-none-any.whl

# 验证安装
skill-seekers --version
```
